# Newsletters folder

Put each month's newsletter PDF here, named exactly like `2026-08.pdf`
(4-digit year, dash, 2-digit month, matching the month it's for).

After uploading a PDF here, also add its name to the list in
`assets/js/newsletters-data.js` — see the instructions at the top of that
file. Both steps are needed for it to show up on the Newsletter page.
